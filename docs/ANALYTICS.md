# パッティング分析の設計（v3）

このアプリで何を記録し、どう集計し、利用者に何が分かるようになるかをまとめた設計書。
実装は `lib/putting-stats.ts`（集計）、`lib/putting.ts`（1ホールの組み立て規則）、`app/(tabs)/analytics.tsx`（画面）。

## 1. ゴール

「パットが下手」ではなく、**どの距離・どのラインで・1ラウンド何打失っているか**を数字で示し、
**何を練習すれば一番スコアが縮むか**まで提示する。

- 利用者が知りたいこと: 自分はうまいのか下手なのか / どこが弱いのか / 何を練習すればいいか / 良くなっているか
- 答え方: 基準のゴルファーとの差（ストロークス・ゲインド = SG）を 1打単位で積み上げる

## 2. 記録する項目（カード v3 = 1ホール1行）

| 項目 | 例 | 使い道 |
|---|---|---|
| 何のパット？（E/Ba/P/Bo/D+） | バーディパット | パーオン率・バーディ奪取率・パーセーブ率。ホールのスコアも決まる（何のパット + パット数 − 1） |
| 1st 距離（整数 m） | 8 | 期待パット数・SG・距離帯の分類 |
| 1st 傾斜（平/上/下）・曲がり（直/左/右） | 上り・右 | ライン別の得意/苦手、グリーンマップの位置 |
| 1st 短/長 | ショート | 寄せの傾向（届いていないか・強すぎるか） |
| 2nd 距離（小数1桁）・傾斜・曲がり | 1.2 平・直 | 1st の「残り距離」＝寄せの質。短いパットの決定力 |
| 3rd 距離（小数1桁） | 0.6 | 3パットの内訳 |
| 計（総パット数） | 2 | カップインの判定。読み取りの検算にも使う |

- 最後に記録したパットがカップイン。計が記録より多ければ（4パット以上）記録した最後も外れ。
- 手入力も同じ項目（`app/hole-input/[id].tsx`）。距離は m か歩数（プロフィールの歩幅で換算）。

## 3. 集計の中心: ストロークス・ゲインド（SG）

### 3.1 期待パット数 E(d)

基準のゴルファーが距離 d からカップインまでに要する平均パット数。3つの基準を切り替えられる。

| 基準 | 出典 |
|---|---|
| PGAツアー平均 | Broadie『Every Shot Counts』の距離別期待パット数（ShotLink） |
| スクラッチ（HC0） | ツアー基準をもとにした概算 |
| アマ平均（HC15前後） | ツアー基準をもとにした概算 |

区間は線形補間。既定はハンディキャップ 5 以下なら HC0、それ以外は HC15。

### 3.2 1打ごとの SG

```
SG(1打) = E(打つ前の距離) − 1 − E(打った後の距離)     （入ったら E(後) = 0）
SG(1ホール) = E(1st 距離) − 総パット数                  （1打ごとの合計と一致する）
```

カード v3 は 1st〜3rd の距離をすべて書くので、1打ごとに評価できる。
これにより「寄せ（6m〜）」「チャンス（2〜6m）」「決め切る（〜2m）」を別々に採点できる
（従来の「平均パット数」「1st パットの成功率」ではできなかった）。

### 3.3 パット数の分解（結論カード）

```
実際のパット数 = 距離の難しさ（Σ E(1st 距離)） − 腕前（Σ SG）
```

「距離の難しさ」はアプローチの結果で、パッティングの腕とは別物。
パット数が多い理由がアプローチ（遠い）なのか、パッティング（入らない/寄らない）なのかが一目で分かる。
値は 18 ホールあたりに換算して表示する。

## 4. 画面で出す集計

| セクション | 集計 | 読み取れること |
|---|---|---|
| 結論 | SG/18H、パット数の分解 | 基準より上か下か、原因がアプローチかパットか |
| グリーンマップ（3D） | 1st パットの位置 × 1/2/3パット | 苦手なシチュエーションの「場所」。赤が固まる所が弱点 |
| 練習の優先順位 | 距離帯別 SG・ライン別 SG/打 × 1ラウンドの出現回数 | 失っている打数が大きい順の練習テーマとドリル（最大3件） |
| どの距離で得/損 | 1打ごとの SG を打つ前の距離で3区分に合計 | 寄せ・チャンス・決め切りのどれで損しているか |
| 距離別カップイン率 | 全パット（1st に限らない）、Wilson 95% 区間、基準の成功率 | 距離ごとの実力と、データがまだ足りないかどうか |
| ロングパットの寄せ | 6m 以上の 1st：平均残り・1m 以内率・3パット率・短/長の割合・距離帯別 | 距離感の癖（ショートばかり / 強すぎ） |
| ライン別 | 7m 以内：傾斜 × 曲がりの 3×3 の SG/打（距離を補正済み）、傾斜別のショート率 | 下りに弱い、左に切れるラインが苦手、など |
| 何のパット | 種類別の回数・平均距離・1パット率・3パット率、パーオン時の平均パット | バーディ奪取率・パーセーブ率 |
| 推移 | ラウンドごとの SG/18H と直近5Rの移動平均 | 良くなっているか |
| 条件別 | パター・グリーン速度・芝・コース別の SG/18H | 1st 距離の違いを補正して比較できる（パターの公平な比較） |

### 4.1 練習の優先順位の決め方

候補ごとに「1ラウンドあたり失っている打数」を計算し、大きい順に並べる。

- 距離帯（〜2m / 2〜6m / 6m〜）: その帯の SG 合計 ÷ ホール数 × 18（8打以上の記録がある帯だけ）
- ライン: 7m 以内の SG/打が一番低いライン × そのラインを1ラウンドで打つ回数
- 0.1打/R 未満は出さない
- 寄せでショートが 60% 以上なら「カップの40cm奥に止める」ドリル、それ以外は「半径1mの円」ドリル

### 4.2 少ないデータの扱い

- 成功率には Wilson の 95% 区間を縦線で出す（回数が少ないほど長い）
- 目安は 5 ラウンド（約90ホール）以上。ヒートマップは 10 回未満のマスを参考扱いと明記

## 5. これで何が分かるようになるか（例: デモデータ）

デモの「HC12 のゴルファー 22 ラウンド」（`lib/demo-data.ts`。下りと右に曲がるラインが苦手・寄せがショートしがち・徐々に上達、という癖を持たせて生成）を分析すると:

- HC15 と比べて 1ラウンド −0.8打。パット数 34.0 = 距離の難しさ 33.2 + 腕前 0.8
- 〜2m は +0.9打と得意、2〜6m で −0.9打、6m〜で −0.7打
- 練習の優先順位: ①2〜6m のチャンス ②下りのライン ③ロングパットの寄せ
- 推移では後半のラウンドほど SG が上向き

旧バージョンの「課題トップ3」は、同じデータで「10m+ の決定率を上げる」を1位に出していた
（10m 以上はツアー選手でも数%しか入らないので、練習テーマとして不適切）。SG にすることでこの種の誤りがなくなる。

## 6. 今後の拡張案

- 基準の個人化: 自分の過去データから E(d) を推定し「先月の自分」と比べる
- 曲がりの量（カップ何個分）の記録 → 読みの癖（プロサイド/アマサイド）の分析
- グリーン速度で E(d) を補正（速いグリーンでは長い距離の期待値が上がる）
- 練習ラウンド（練習グリーン）の記録モードと、ドリルの達成率の記録
